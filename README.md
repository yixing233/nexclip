# NexClip Web 控制台

NexClip Web 控制台是基于 React 19、Vite 与 Tailwind CSS 构建的跨平台响应式管理面板。

---

## 核心特性

- **多设备状态管理**：实时查看在线设备列表与心跳状态。
- **剪贴板云端历史**：在线查看、搜索、复制或删除剪贴板历史。
- **即时发送与流转**：通过网页直接向指定设备或广播发送剪贴板内容与文本。
- **响应式设计**：完美适配桌面端与移动端浏览器。

---

## 运行与开发

### 环境要求
- Node.js 18+

### 快速启动

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 编译生产版本
npm run build
```
