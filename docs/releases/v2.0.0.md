# NexClip Tauri v2.0.0 - Windows

首个 Tauri 2 + React + Rust 实现的 Windows x64 正式版。

## Windows

- 改善剪贴板稳定性：图片读取、解码与处理移出全局剪贴板锁的持有阶段，增加采集与写入超时恢复，降低连续接收大图时的卡顿。
- 补齐超限图片提示：超过 10 MB 的图片保留本地占位与预览，不自动上传同步。
- 完善互传消息显示：修复其他设备消息缺失、本机消息方向、时间与日期分隔；进入页面默认定位最新消息，查看旧消息时保留阅读位置。
- 调整互传布局：悬浮模糊输入区域、紧凑设备栏、清空记录图标、统一文本和图片右键菜单；清空或删除的消息在重启后保持删除状态。
- 提供二进制文件互传入口，支持文件选择与拖放发送，文件消息与文本消息按时间混排，文件记录在重启后保留。
- 完善设置联动、开机自启动、热键、截图标注、滚动截图和桌面贴图；修复图标库映射、列表滚动恢复、图片预览键盘事件与异步监听清理。
- 分离 Tauri 与 WinUI 更新通道：Tauri 仅识别专属安装包，读取 GitHub 资产 SHA-256 校验值；直连服务器尚无 Tauri 通道时自动检查 GitHub。

## 安装与迁移

- 适用于 Windows 10 1809 及以上版本、Windows 11，x64 架构。需要 WebView2 Runtime，缺失时安装器会联网下载。
- 安装包：`NexClip_Tauri_2.0.0_x64-setup.exe`。默认安装目录为 `%LOCALAPPDATA%\NexClip Tauri`，卸载项名称为 `NexClip Tauri`，与 WinUI 分开。
- 安装及启动前请退出旧 WinUI 客户端，一次只运行一个版本。安装器保留旧 WinUI 安装，迁移后可按需卸载旧版。
- 两版共用 `%APPDATA%\NexClip` 配置，以及 `%LOCALAPPDATA%\NexClip` 默认历史目录；自定义存储目录沿用已有设置。Tauri 卸载保留这些共用数据。
- 两版共用 `NexClip` 开机启动项，Tauri 启动时按当前设置接管该项。卸载 Tauri 后若返回 WinUI，请在旧版设置中重新开启需要的开机自启动。
- 卸载界面的应用数据选项只处理 Tauri/WebView 缓存，共用的剪贴板历史与配置继续保留。
- 本安装包未进行 Authenticode 代码签名。
- 服务器直连已提供独立的 `windowsTauri` 更新通道及安装包；选择直连时可直接检查和下载 Tauri 更新。
