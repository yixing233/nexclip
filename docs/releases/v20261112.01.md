# NexClip v20261112.01 - Windows

## 本次更新

### 复制直达

- 修复关闭“新内容通知”后，其他设备同步来的链接无法触发复制直达的问题。
- 远端新文本按复制直达总开关和分类开关进行智能识别，直达卡片优先显示，避免被通用通知覆盖。

### 图片预览

- 图片预览的画布、标题栏、工具栏、文字和图标统一跟随应用主题。
- 浅色主题使用浅色背景与深色图标，切换主题时同步更新。

### 内存与后台运行

- 历史列表和即时互传的图片、来源应用图标按需加载，列表容器回收及托盘空闲时释放预览缓存。
- 窗口隐藏期间合并历史刷新请求，重新打开时统一刷新。
- 当前图片预览按显示尺寸限制解码，减少大图的位图内存开销。

## 升级说明

- 本次发布为 Windows x64 客户端更新，可覆盖安装，保留现有配置与历史记录。
- Android 客户端和服务端程序无需更新。
